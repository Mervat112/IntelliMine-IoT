# IntelliMine IoT

## Smart Gas Monitoring System using ESP32

This project monitors:
- Temperature
- Humidity
- Gas Level

The ESP32 sends sensor readings to an MQTT broker, and Node-RED displays the data on a dashboard.

## Components
- ESP32
- DHT22 Sensor
- MQ2 Gas Sensor
- Buzzer

## Technologies
- MicroPython
- MQTT (HiveMQ)
- Node-RED Dashboard
- Wokwi
